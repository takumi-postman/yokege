# よけゲー

エジプトの砂漠を舞台にした、落ちてくるクリップをよけるブラウザゲーム。
HTMLファイル1枚で動きます。ビルドもインストールも不要です。

遊ぶ: https://takumi-postman.github.io/yokege/

## 中身

| ファイル | 何か |
|---|---|
| `index.html` | ゲーム本体。これ1枚で完結しています |
| `順位表_AppsScript.gs` | 順位表の保存先。Googleスプレッドシートに貼るコード |

## 遊び方

- マウス、指、矢印キーで再生ヘッドを左右に動かす
- **赤** に当たったら終わり
- **緑** を取ると落ちる速さが落ちる
- **壺** を取るとヘビが出て、降ってきたばかりの赤を食べる
- **ダイヤ** を取ると5秒間シールドが張られる
- **ハサミ** は3本まで持てて、1本につき赤1個ぶん耐えられる
- **スカラベ** はいちばん下の赤を画面外へ押し返す
- **リップル削除** は画面の赤を全部消して、速度と難易度を巻き戻す

35秒ごとに時間帯が変わり、8つで砂漠の一日が一周します。ときどき砂嵐が吹きます。

## 数字をいじる

`index.html` の先頭にある `CONFIG` の数字を変えるだけで手ざわりが変わります。
落ちる速さ、出現の間隔、アイテムの確率、減速の強さなど、全部そこにまとまっています。

## 順位表をつなぐ

1. Googleスプレッドシートを新規作成
2. 拡張機能 → Apps Script
3. `順位表_AppsScript.gs` の中身を貼り付け
4. デプロイ → 新しいデプロイ → ウェブアプリ（アクセスできるユーザー: **全員**）
5. 出てきたURLを `index.html` の `LEADERBOARD.endpoint` に入れる
